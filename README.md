# AURORA — Personal Command Centre

A local, private productivity workspace for your browser.

## Live site

https://popcornparty.github.io/aurora-command-centre/

## What works

- Hash-based navigation (survives refresh, works on iPhone and desktop)
- Home dashboard showing real counts from your local tasks, notes and projects
- Tasks (add, complete, priority, search, filter, delete)
- Notes (create, edit, pin, search, delete)
- Projects (create, describe, search, delete)
- Bookmarks (add, validate URL, open, delete)
- Scratchpad (autosave, copy, download, clear)
- Calculator, Unit Converter, Timer, Stopwatch
- Text utilities, JSON formatter/validator, Colour converter
- Date calculator, Password generator (local only), File viewer (local only)
- Settings: accent colour, overlay strength, reduce motion, 12-hour clock
- Full export / import / reset of all local data
- Ferrari rainy-night background with adjustable overlay

## Data privacy

Everything is stored in your browser’s localStorage. Nothing is sent to any server. Clearing site data or switching browsers/devices will remove your notes and tasks. Use the export feature regularly if you want a backup.

## GitHub Pages

Source is set to **GitHub Actions** in Settings → Pages. Every push to main builds and deploys.
