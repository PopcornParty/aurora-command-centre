# AURORA — Cinematic Personal Command Centre

Premium dark dashboard for @popcorn_party1.

## Live site

https://popcornparty.github.io/aurora-command-centre/

## What works

- Hash-based navigation (survives refresh and works on iPhone / desktop)
- Sidebar with active indicator + mobile bottom navigation
- Notes, Tasks, Calculator, Unit Converter, Timer/Stopwatch, Scratchpad, Bookmarks (all saved locally)
- Channel Stats dashboard with KPIs, charts, searchable/sortable tables, date-range filter, refresh, rankings and recent activity — clearly labelled DEMO DATA
- Import your own stats data on the Channel Stats page (stored locally)
- System Monitor (browser/device info only — not a server monitor)
- Settings: accent colour, reduce-motion override, export/import/reset of local data
- Ferrari rainy-night background (uploaded photo + CSS rain)

## Demo data

Channel Stats and smart-home sections use sample values marked DEMO or Not connected. Nothing is live until you import data or connect a real source later.

## GitHub Pages

Source must be set to **GitHub Actions** in Settings → Pages. Every push to main builds and deploys.
